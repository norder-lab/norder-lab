情報系 / データサイエンス専攻の大学生です.  
2019年に `Java` の厳格なオブジェクト指向からプログラミングを始め, そこで培った設計思想をベースに現在は `Rust` や `Python` を主軸として開発を行っています.  

特定のOSやマシンスペックに依存しない「疎結合でシンプルな構成」を好みます.  
どんな環境でも軽快に動作し, マウスを介さずキーボード完結で扱える操作感を重視しているため, 主に TUI / CLI ツールや軽量なユーティリティを制作しています.  
自作の TUI ツールには, 原則として `Vim` キーバインドを備えるのがこだわりです.  

言語ごとに役割を明確に捉えて使い分けています.  
高速性とメモリ安全性が求められる信頼性の高いツール開発には `Rust` を選び, データ分析や機械学習, 豊富なエコシステムを活かしたプロトタイピングには `Python` を活用しています.  

今後は, 機械学習によって構築したモデルと実用的なプロダクトを掛け合わせたツール開発にも挑戦していきます.  
AI や時代の変化によって扱う技術領域が大きく移り変わっても, 常に好奇心を持って柔軟に適応し続けられるエンジニアを目指しています.  

このアカウントでは, 自作ツール (TUI / GUI) や大学の課題で制作したプロダクト, 普段の開発環境の設定ファイルなどを公開しています.  
また, Qiita では個人開発の知見や技術検証, 学びの備忘録などを発信しています.
